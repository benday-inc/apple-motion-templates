## Templates Included

### Callout Text Templates
- **Callout Text (Box Only)** - Clean text callout with box frame
- **Callout Text (Box Only v2)** - Updated version with enhanced styling
- **Callout Text (Left)** - Left-aligned callout
- **Callout Text (Right)** - Right-aligned callout

### Red Arrow Templates
- **Red Arrow with Fade** - Animated arrow with fade effect
- **Red Arrow with Fade (Down)** - Downward pointing arrow
- **Red Arrow with Fade (Left)** - Left pointing arrow
- **Red Arrow with Fade (Right)** - Right pointing arrow
- **Red Arrow with Fade (Up)** - Upward pointing arrow

### Red Rectangle Templates
- **Red Rectangle v2** - Rectangular callout element (deprecated)
- **Red Rectangle v4** - Updated rectangular callout

## Installation

1. Download or clone this repository
2. Copy the template folders to one of these locations:
   - `~/Movies/Motion Templates.localized/Titles.localized/` (user-specific)
   - `/Library/Application Support/Final Cut Pro/Templates.localized/Titles.localized/` (system-wide)
3. Restart Final Cut Pro
4. Templates will appear in the Titles browser

## Usage

1. Open Final Cut Pro
2. Go to the Titles browser
3. Find the templates in your library
4. Drag and drop onto your timeline
5. Customize text and parameters in the inspector

## Requirements

- Final Cut Pro 10.4 or later
- macOS
